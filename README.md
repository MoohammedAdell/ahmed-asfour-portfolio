# Ahmed Asfour — Flutter Developer Portfolio

A modern, high-performance, responsive portfolio website for **Ahmed Asfour**, Flutter Developer.

Built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🚀 Quick Start

Ensure you have Node.js (v18+ recommended) installed.

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## ⚙️ Modifying Portfolio Data

All website content (Bio, Skills, Work Experience, Projects, Services, Contact Details) is stored inside a single file:

```
data/portfolio.ts
```

Updating this file automatically changes the website content across all components without breaking design or layout.
